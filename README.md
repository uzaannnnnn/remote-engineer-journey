# Day 2 Reflections

- "Print" is used to display output to the user, while "Return" is used to send a value back from a function so it can be used elsewhere in the program
- "Elif" is used when there are multiple conditions, ensuring that only one condition is executed after the previous conditions fail, instead of checking all conditions separately with multiple "if" statements
- This logic can be used in real application such as "Student Assessment", "User Access Control" or "Decision-Making Systems"
